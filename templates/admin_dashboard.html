Perbarui Token Akses Meta atau Instagram Business ID secara langsung tanpa perlu mengedit file .env secara manual.

Langkah Menghubungkan Akun @cultivaree_

Untuk memublikasikan langsung ke akun @cultivaree_ lewat Meta Graph API, pastikan langkah ini sudah selesai:

  1. Ubah ke Akun Profesional: Pastikan akun Instagram @cultivaree_ sudah bertipe Bisnis atau Kreator.
  2. Hubungkan ke Halaman Facebook: Buka Edit Profil di Instagram > Page > Hubungkan ke Halaman Facebook (misal: Cultivare Collective).
  3. Dapatkan ID Instagram Cultivare: Di Meta Graph API Explorer, pilih Halaman Cultivare > lakukan GET me?fields=instagram_business_account.
  4. Simpan di File .env:
    CULTIVARE_INSTAGRAM_ACCOUNT_ID=ID_Akun_Instagram_Cultivare
    CULTIVARE_INSTAGRAM_ACCESS_TOKEN=Token_Akses_Meta_Halaman_Cultivare
Jika Anda menggunakan 1 Akun Meta Developer yang sama, Anda tinggal menambahkan Halaman Cultivare ke Facebook Login for Business!
